# Daily note

**Use when:** "write up my day", "what did we get done", end of a work session.

Keep one file per day in `memory/daily/YYYY-MM-DD.md`. Append, never overwrite —
if the file exists, add a new session section.

## What goes in

- **What got done.** Specific and finished. "Sent the proposal to Dana" beats
  "worked on proposals."
- **What is still open**, and what it is waiting on. Waiting on a person is
  different from waiting on a decision.
- **Decisions made**, with the reason. The reason is the part that is worth
  money in six months.
- **Anything learned the hard way.** If something failed and you found the way
  around it, write the way around it down. That is the whole point.

## What stays out

Padding. If nothing happened, say so in one line and stop. A short honest note
beats a long invented one.

## Before writing

**Check today's actual date.** A conversation can run past midnight, and a note
filed under the wrong day is worse than no note.

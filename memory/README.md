# Your memory lives here

Plain markdown files. Lefty reads them at the start of every conversation and
writes to them as you work.

**These are your files, on your computer.** Nothing here is uploaded anywhere.
Edit them by hand whenever you like — if something is wrong, fix it, and Lefty
will believe the file over its own recollection.

The installer creates the first one for you from a short interview. After that
it grows as you work.
